## 风险登记

| 风险 | 应对 | 状态 |
| --- | --- | --- |
| 编造回忆 | 每条事实和情景带出处；无出处的回忆用不确定语气 | 待设计（P0-05、P0-07） |

| 群聊隐私 | 告知群成员；“忘掉这件事”指令；数据只在本地 | 待实现（P1-06、P1-07） |
| 订阅额度用尽或 app-server 接口变动 | 额度监控自动切 API；核心不依赖它也能运行 | 待实现（P0-09） |

- 完成一项任务：把 `[ ]` 改成 `[x]`，行尾写完成日期，并同步“进度总览”的计数。

- 做出新决定：写进“决策记录”，必要时同步修改报告。
- 每次有实质变化：在“变更日志”加一行，并更新顶部的“最后更新”日期。
