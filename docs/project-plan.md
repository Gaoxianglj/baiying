### 阶段 0 · 地基（关口 G0）

- [x] P0-01 初始化仓库：git init、Python 项目骨架（pyproject）、目录结构、`.gitignore` 排除记忆数据与密钥（2026-10-22）
- [x] P0-02 配置与密钥：配置文件（模型、路径、阈值），密钥只放环境变量或 `.env`（2026-10-22）
    - 优先级：代码默认值 < `config.toml` < `config.local.toml` < `.env` < 环境变量；toml 里写 API key 会直接报错；`companion config` 打印生效配置（密钥打码）
- [x] P0-03 记忆文件夹格式：事件 JSONL 结构、`manifest.json`、`self/` 与 `people/` 模板，记忆目录单独做 git 版本化（2026-10-22）
    - `companion init` 创建 `data/memory/`，可重复执行、不覆盖已有文件；记忆仓库的提交作者是“白璎”；`index.sqlite` 等派生层不进 git
    - 事件按 UTC 月份写入 `events/YYYY-MM.jsonl`，时间戳必须带时区，未知字段拒收，写到一半损坏的行读取时跳过
- [x] P0-04 事件写入接口：统一事件结构（谁、哪个身体与频道、时间、原始内容）；人物表与跨平台身份绑定（2026-10-22）
    - `Ingest.record` / `record_self`：所有身体通过它上报事件；陌生账号自动建档，见到新昵称记进 names
    - 人物档案 `people/<id>.md`：YAML frontmatter（名字、各平台账号）+ 正文，可手改，重写时保留正文
    - `companion people list / add / bind`：bind 即你的确认；被绑走全部账号的旧档案记为 `merged_into`，旧事件仍能找到同一个人
- [x] P0-05 SQLite 派生层：情景表、事实表（有效期、出处、置信度）、记忆强度字段、FTS5 全文索引（2026-10-22）
    - `MemoryIndex`：情景（参与者、出处事件、重要度、情绪、鲜活/淡化/压缩/沉睡状态）；事实用 `supersedes` 标记失效而不删除，`fact_history` 可说出“以前……后来……”
    - 记忆强度：R = e^(−Δt/S)，被回忆时 S 按重要度增长，钉住的不衰减；参数集中在 `memory/forgetting.py`
    - 中文检索：中日韩文字切成二字组（另收单字）交给 FTS5，“咖啡”这类两字词也能搜到；失效事实与沉睡情景不出现在检索结果中
- [x] P0-06 向量检索：embedding 接口与向量存储，实现“关键词 + 向量 + 人物 + 时间”混合检索（2026-10-23）
    - 本地 Ollama 的 OpenAI 兼容接口；向量（float32、归一化）存 `index.sqlite`，记录由哪个模型算出，换模型自动重算
    - 评测（`scripts/eval_embeddings.py`，22 条中文记忆、25 个多为换说法的查询）：选 **qwen3-embedding:4b、不加查询前缀**；生产设置下前 1 命中 96%、前 3 命中 100%，每次检索约 18 ms
    - 发现关键词与向量等权融合反而更差（前 1 命中 76%），因为“小明”这类名字到处出现；改为向量排序为主、关键词结果豁免余弦门槛（0.55），向量服务不可用时自动退化为纯关键词
- [x] P0-07 上下文组装器：常驻档案 + 混合检索，按“相关度 × 记忆强度 × 重要度”排序（2026-10-23）
    - 常驻：种子、自我认知、表达风格、对话者档案、关于 ta 的当前事实（钉住和重要的优先）、最近 3 段共同经历
    - 检索：最多 8 条，沉睡的不出现，淡化的标注“记得不太清了”；被放进上下文的记忆记一次回忆（变牢固）
    - 同一频道 6 小时内最近 20 条对话；提示词要求只依据记忆谈过去、记不清就直说
- [x] P0-08 模型网关：统一接口；后端 1 为 Codex app-server（ChatGPT Plus），后端 2 为指定 API，后端 3 为本地模型（预留）（2026-10-23）
    - `ModelGateway` 按 订阅 → DeepSeek → 本地 依次尝试；`prefer` 可强制指定后端（G0 切换测试用）；`chat_json` 统一处理 JSON 输出
    - DeepSeek 实测：关闭思考模式后回复约 1.8 秒（开启时 3.4 秒、输出 token 多约 7 倍），已默认关闭
- [x] P0-09 额度监控与切换：读取 `account/rateLimits/read`，5 小时窗口耗尽时切到 DeepSeek，重置后切回；记录 DeepSeek 用量，接近每月 20 美元时告警（2026-10-23）
    - 额度每 60 秒读一次；任一窗口用到 99% 或调用报额度错误即暂停订阅，直到窗口重置（读不到重置时间则暂停 10 分钟）

    - 用模拟 app-server 测试通过；真实额度数据待 Codex 安装后核对
- [x] P0-10 Codex app-server 聊天化（2026-10-23）：人格指令替换内置指令，关闭命令执行与搜索，只读沙箱；实测首字延迟并记录

- [x] P1-09 看图（2026-10-24）

    - 主模型 = GPT 订阅（Codex `localImage`）→ DeepSeek（`image_url`）；看图结果是一句中文描述写进记忆，原图转 JPEG（长边 1024）按哈希存在 `memory/media/`（不进 git），“忘掉”时一并删除
