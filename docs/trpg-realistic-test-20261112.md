## 测试发现并修复

1. 卡解析原先只兼容部分表格，白璎生成的逐行或紧凑Markdown无法绑定。补齐明确属性、技能、幸运与实际携带物品的解析；冲突数值和缺八属性的JSON拒绝默认补齐。有卡文件时优先采用文件数据，避免旁传的不完整对象覆盖姓名/幸运。候选装备不当成已携带。
2. 公开场景列表只显示当前位置和已到达场景，曾被误判为保存失败。新增筹备总数、绑定核验、批量场景和草案开场选择，补齐工具说明；已有进度不通过筹备工具重置位置。
3. 接话过滤曾忽略“重新/仔细”等修饰词、明确行动别名及短目标回答。补齐动作入口，记录当前玩家、同团同版本、180秒内的具体提问；短确认只接明确是非问题，不将其他群成员或普通闲聊一并接入。
4. 暂停后曾继续附带“投吧”，待确认改行动时还出现没有登记的取消确认问句。暂停提示与待确认反馈改为明确的程序状态，减少不必要模型调用，仍保留实际风险和取消选项。
5. 模型曾把失败的登记行动改成普通技能检定，绕开菜单中的禁重投。增加服务端校验，在提出和提交两处均核对当前场景、技能、失败记录与条件指纹；换表达或入口不能重置骰点。
