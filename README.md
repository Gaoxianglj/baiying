# 白璎：长期记忆 AI 伙伴

一个记忆与人格都存在本地的 AI 伙伴。核心是长期记忆与分层人格；QQ 聊天和《我的世界》是两个接入的“身体”，模型后端可以随时切换，记忆、人物关系和表达习惯不会丢。

私有仓库。公开后不允许商用。

## 快速开始与常用命令

需要 [uv](https://docs.astral.sh/uv/) 和 Python 3.12+（当前推荐 Python 3.13）。

```bash
uv sync
uv run companion config                  # 查看生效配置（密钥打码）
uv run companion init                    # 初始化记忆文件夹 data/memory/
uv run companion people list             # 查看人物表与跨平台账号绑定
uv run companion chat --as <你的id>       # 命令行本地聊天
uv run companion qq                      # 连接 NapCat，在 QQ 上运行
uv run companion web                     # 本机控制台：概览、今天与约定、设置、自我与风格、人物与记忆、表情包、技能、日记、跑团
uv run companion extract --force         # 手动整理尚未抽取的对话
uv run companion sleep                   # 手动执行一次完整“睡眠”
uv run companion status                  # 查看模型后端状态、花费与记忆统计
uv run python scripts/replay.py          # 用当前提示词重放真实聊天，与历史回复并排对比
uv run pytest
uv run ruff check .
```

## 一键启停（后台运行）

- `start.bat`：依次启动 Ollama → NapCat（按 `.env` 的 `QQ_BOT_ACCOUNT` 快速登录；需扫码时自动弹出二维码图片）→ 主程序 → 控制台，全部在后台运行，关窗不退出；最后打开固定地址的本机控制台。
- `stop.bat`：主程序先整理完未抽对话再安全退出；随后停控制台、NapCat（仅停 NapCat 目录内的 QQ，不动日常 QQ）与 Ollama。保留某项：`stop.bat -KeepOllama` / `-KeepNapCat`。
- `status.bat`：查看各服务运行状态。
- 主程序与控制台崩溃后 5 秒自动拉起，并通过进程锁保证单实例运行。
- 日志位于 `data/logs/`（`qq-日期.log`、`web-日期.log`），运行状态与锁文件在 `data/run/`。
- `.env` 可配置 `NAPCAT_DIR` 与 `CONSOLE_PORT`（默认 `8765`）。

## 分层人格、熟络度与周期反思

人格与关系数据以可读 Markdown 存在 `data/memory/`（自动做本地 git 版本记录），并在控制台「自我」与「人物」页支持查看和手动调整：

- **核心层 `self/seed.md`**：核心性格、基本外貌印象、知识边界与不可逾越的底线；仅由主人修改，反思不改动。
- **次核心层 `self/preferences.md`**：穿搭随身物、读书品味、日常喜好与近期熟悉的新事物。
- **自我认知 `self/identity.md`**：长期相处中对自己的认识。
- **表达风格 `self/style.md`**：全局口头禅、句式节奏、熟人间的“破壳”打趣分寸与收尾习惯。
- **人物档案与四档熟络度 `people/*.md`**：每个人维护偏好、关系、共同经历、专属说法、**离散四档熟络度（`初识` / `相熟` / `熟络` / `亲近`）**以及针对此人的 `对 ta 的说话方式`。

**反思与更新节奏**：
- 每日凌晨睡眠：更新当日发生过互动的人物经历/偏好，写日记，并生成新一天的 AI 日常安排。
- 每 **7 天** 同步一次深度反思（`sleep.identity_every_days = 7`）：同步审视 `identity.md`、`preferences.md`、`style.md` 以及有互动者的熟络度与对 ta 说话方式；若无充分新依据允许明确返回“不更新”，保持人设稳定不漂移。

## 一日一会话与上下文瘦身

默认开启 `models.subscription.persistent_chats = true`（控制台“聊天保持上下文”），目标是用**一条连续上下文覆盖一个频道的一整天**，同时避免重复塞入设定造成的干扰与开销：

- **按槽位与事件号增量去重**：线程索引与已投递标记保存在 `data/run/chat-sessions.sqlite`（不含正文）。核心人格（四层档案与说话规则）、表情包表、技能声明、技能实时状态、每位发言人的档案与事实、今日安排、当前心情、跨聊天近期经历与检索记忆均按状态槽位（`state@<槽位>=<哈希>`）或事件号独立去重——仅在首轮或内容真正变化时增量补发，状态从 `A → B → A` 回落也能准确刷新；常规稳态轮末尾只附带百余字的当前时刻、发言人熟络度与接话判断。
- **日间不断线**：
  - 群聊内不同熟络度群友（`初识`～`亲近`/主人）交替发言时，原生工具表按频道级声明保持恒定，不触发 `policy-change` 重开线程；执行层仍严格校验当前发言人权限与熟络度。
  - 日间 30 分钟空闲抽取产生事实纠正或新增经历时，不再清空当日聊天线程，下一轮自动通过人物槽位推送最新事实。
  - 正常启停或服务重启后优先通过 `thread/resume` 接回当日线程；若历史缺失或上一轮状态不确定则自动从近 24 小时事件安全重建。
- **何时轮换新线程**：仅在每日凌晨睡眠总结（先强制分批整理全部会话并提交游标，成功后轮换）、主动 `/忘掉` 记忆或控制台手动修改自我档案/熟络度/解除约定时开启新一轮线程；后台任务线程始终独立，不受聊天轮换影响。
- **跨聊天共享与兜底保留**：私聊与群聊共享长期记忆，并可即时回忆近 24 小时其他聊天的相关普通消息（最多 6 条，标明来源且不授予跨聊工具权限）。记忆抽取、反思、看图、屏幕与剪贴板仍走独立临时会话；GPT 订阅额度触顶时自动切到 DeepSeek 兜底 API，保留完整无状态提示词，切回主通道时自动同步缺口期间的对话。
- **底座边界约束**：`codex app-server` 通过独立 `codex_home`（可在 `config.local.toml` 指定如 `data/run/codex-home`）隔离运行，关闭 Codex 自带记忆、MCP、命令行与联网；并在底座指令中约束即使面对代码或运维提问也不切回编程助手模式。
- **群聊自然接话**：群内未 `@` 但句首/句末点名（如“白璎……”）直接回应，句中提及按上下文顺手判断是否接话；合并转发记录与图片 OCR 中出现的名字不会误触发点名。

## 统一约定系统

约定系统已全面替代原有的定时提醒，数据保存在 `data/reminders.json`，在控制台「今天」页可直接查看与解除：

- **三类约定**：
  1. **准点 / 重复提醒**：如具体时刻（`18:30`、`明天 9:00`、`30分钟后`）或规律周期（`每天 08:00`、`每周一 09:00`、`工作日 08:00`）。
  2. **弹性时段行动约定**：支持模糊时段（`每天`、`每天 下午`、`每周五 晚上`、`明天起 每天 早上`），到时间可自主调用受控技能完成并存档（如每天画一朵不重样的花收进花册、写小笺、做图册），支持默认完成后分享或 `静默` 后台存好不打扰；额度暂满时自动顺延，不丢周期。
  3. **持续相处约定**：时间写 `持续`，作为长期遵守的互动约定自动注入当前会话上下文。
- **自然语言触发与防漏自检**：无需特殊命令词，聊天中自然达成、调整或取消约定时，白璎会主动调用【约定】/【修改约定】/【解除约定】落盘，并配有防口头答应漏登记自检（兼容旧【提醒】/【取消提醒】别名）。
- **权限边界**：私聊默认可用（受 `skills.reminders.owner_only` 控制）；群聊仅允许**熟络及以上的朋友或主人**建立、修改和触发群约定，防陌生群友滥用。

## 权限与技能体系

权限由程序强制校验（`src/companion/skills/access.py`、`history.py`、`reminder.py` 等），不依赖模型自觉：

| 资源 / 操作 | 群聊、别人的私聊 | 主人私聊 |
| --- | --- | --- |
| 聊天记录和里面的图 | 当前聊天；群聊可按 `skills.history.scope` 翻其他群 | 全部 |
| 当前聊天文件夹 `data/workspace/chats/<聊天>/` | 能存新文件、能读、能发 | 同左 |
| 当前聊天收到的文件 | 能读、能发 | 同左 |
| 别的聊天的文件夹和收到的文件 | 不行 | 能读、能发 |
| 本机其他文件 | 不行（`skills.files.group_read_paths` 仅只读） | 能读、能发、能看图、能按名字找 |
| 存新文件到别处 | 不行 | 能（系统、隐藏、程序自身目录除外） |
| 改已有文件 | 不行 | 不直接改，交电脑助手（越权须审批） |
| 黑名单（密钥、记忆、登录态、浏览器与密码管理器数据） | 不行 | 不行 |
| 屏幕与剪贴板 | 不行（不进入提示词） | 默认关闭；开启后仅当轮临时会话使用，截图即删，跳过密码管理器内容 |
| 群聊建立/触发约定 | 仅限熟络及以上或主人 | 主人私聊与白名单群均可用 |

可用技能涵盖：【约定】【修改约定】【解除约定】【搜索】【画】【画动图】【翻记录】【看图】【存图】【发图】【做图册】【写文件】【发文件】【读文件】【读页】【查文档】【转存文件】【看目录】【找文件】【群文件】【掷骰】【检定】【团务】【任务】【任务状态】【继续任务】【停止任务】【追加任务】【压缩任务】，主人私聊还支持电脑助手与【看屏幕】【读剪贴板】。QQ 上还支持收藏表情包、消息表情回应、戳一戳与群语音。

## 文件保存、PDF 读取与后台任务

- **统一聊天目录**：每个聊天固定使用一个文件夹（群聊 `data/workspace/chats/group-群号/`、私聊 `data/workspace/chats/private-QQ号/`），不再按日期分层；重名写入自动编号不覆盖原文件，支持 `.xlsx` 工作表及公式缓存值读取与群云端文件自动拉取。历史收件可用 `uv run python scripts/migrate-chat-files.py` 预览并加 `--apply` 迁移。
- **PDF 按页识别与缓存**：依赖 `pypdf[crypto]` 与 `pypdfium2`；支持普通文本分段读、【读页】视觉看原页图、【查文档】检索页码，以及【转存文件】后台全文提取与扫描页 OCR（按内容指纹缓存于 `data/run/documents/`）。
- **后台任务与续跑**：技能调用不设轮次上限，长耗时多步任务可通过【任务】或 `/任务` 交后台执行，状态落盘于 `data/run/tasks.json`（会话索引 `data/run/task-sessions.sqlite`）。支持 `/任务状态`、`/追加任务`、`/停止任务`、`/压缩任务`、`/继续任务`；重启后活跃任务明确标为“已中断”以供核对续跑，附件发送带独立回执不盲目重发。
- **Codex 原生动态工具**：默认启用 `models.subscription.native_tools = true`，把 Python 技能暴露为结构化工具；不兼容时自动回退文本标记。若需临时回退旧行为，可在控制台关闭“使用原生工具调用”或“PDF 按页读取和缓存”并重启。

## 真实骰子与跑团

- **真实骰子**：支持 `.r 2d6+6`、`/检定 60｜困难｜奖1｜侦查`、`/骰记录`，直出不耗模型，采用系统随机与 CoC 七版奖惩骰规则并记录审计日志（见 [docs/dice.md](docs/dice.md)）。
- **跑团系统与 AI 主持**：支持 QQ `/团 帮助` 与控制台「跑团」面板，具备独立团务与角色卡存档、正式检定事务、KP 资料与普通聊天隔离以及独立 AI 主持接续（见 [docs/trpg-system.md](docs/trpg-system.md) 与 [docs/trpg-ai-host.md](docs/trpg-ai-host.md)）。

## 配置与网络

- 配置优先级：`config.toml`（入库默认值）< `config.local.toml`（本机覆盖，不入库）< `.env`（本机密钥与路径）< 环境变量。API Key 仅允许放 `.env` 或环境变量（参考 `.env.example`）。
- 本机 Ollama 等回环地址连接自动直连，避免系统代理拦截 `localhost`；远端 API 保持原有代理与证书环境。
